# Partisymboler

Partisymbolerna lagras i respektive `data/parti/<filnamn>/` och refereras från partiets `index.json`. Filnamnet består av partikoden i källan och en namn-slug, exempelvis `0001-moderaterna.png`.

## Källor

- Aktuella symboler: Valmyndighetens [symboler för deltagande partier i val 2026](https://data.val.se/filer/val2026/parti/partisymboler.zip). Importerad ZIP hade SHA-256 `950d899eba71009562d702e6bb28baf59813cfcfa0d4ee62f4eab1f50a83dfbf` den 23 augusti 2026.
- Äldre reservsymboler: Valmyndighetens [arkiv över registrerade partibeteckningar inför EU-valet 2019](https://historik.val.se/val/ep2019/regpartier/kontaktuppgifter.html). De används endast för partier som saknar symbol i 2026-paketet.

Valmyndigheten anger att deras data är fri att använda om myndigheten anges som källa. Partisymbolerna kan samtidigt vara skyddade som varumärken. Projektets CC0-dedikation innebär inte att eventuella varumärkesrättigheter upphör.
